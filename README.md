## 📌 About the Project

The **Student Information System (SIS)** is a menu-driven application developed using **16-bit NASM Assembly Language**. It is designed to manage basic student information and academic records through a simple, user-friendly interface.

This project demonstrates fundamental assembly language concepts, including input/output operations, conditional jumps, loops, procedures, and menu-based program control.

## ✨ Features

- 🧑‍🎓 **Student Admission** — Enter student information.
- 📋 **Student Status** — Manage student status.
- 💰 **Fee Management** — Handle student fee information.
- 📅 **Attendance Management** — Maintain attendance records.
- 📊 **Results Management** — Manage academic results.
- 🩺 **Health Records** — Record health and disability information.
- 👥 **View All Students** — Display student information.
- 🚪 **Exit** — Close the application.

## 🛠️ Technologies Used

- **Programming Language:** NASM Assembly (16-bit)
- **Execution Environment:** DOSBox
- **Output Format:** `.COM` executable
- **Operating Environment:** DOS-compatible environment

## ▶️ How to Run

### Step 1: Install the Tools
Install NASM and DOSBox on your computer.

### Step 2: Assemble the Program
Open Command Prompt or a terminal in the project folder and run:

```bash
nasm -f bin student_info_system.asm -o sis.com
```

### Step 3: Run in DOSBox
Open DOSBox, navigate to the folder containing `sis.com`, and execute:

```text
sis.com
```
